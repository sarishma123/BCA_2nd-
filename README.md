# HTML & CSS Practice Project

A collection of HTML and CSS practice files created while learning core web development concepts — tags, layout, and styling methods.

## 📁 Project Structure

```
├── assets/                     # Images and other media used across pages
├── pages/                      # Additional project pages
├── index.html                  # Main entry point of the project
├── certificate.html            # Practice page (certificate layout)
├── div tag.html                # Practice with <div> elements
├── html_css_html_design.html   # Combined HTML + CSS design practice
├── htmllist.html                # HTML list elements practice
├── htmllist.css                # Styles for htmllist.html
├── inline css.html             # Example of inline CSS styling
├── internal css.html           # Example of internal (embedded) CSS styling
├── list.html                   # List elements practice
├── style.css                   # Shared stylesheet
└── README.md                   # Project documentation
```

## 🎯 Purpose

This repository documents my progress while learning HTML and CSS. Each file focuses on a specific concept:

| File | Concept Practiced |
|------|-------------------|
| `div tag.html` | Using `<div>` for layout structuring |
| `htmllist.html` / `list.html` | Ordered and unordered lists |
| `inline css.html` | Applying CSS directly via the `style` attribute |
| `internal css.html` | Applying CSS using a `<style>` block |
| `html_css_html_design.html` | Combining HTML structure with CSS design |
| `certificate.html` | Building a real-world style layout (certificate) |

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to View

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Explore the other `.html` files individually to see each concept in action.

## 📌 Notes

- `style.css` and `htmllist.css` are external stylesheets linked to their respective HTML files.
- This project is for learning purposes and will keep growing as new concepts are practiced.
